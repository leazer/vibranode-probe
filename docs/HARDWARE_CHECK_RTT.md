# 单板 RTT 验证（当前优先入口）

本轮先验证探头，RS-485/TAB5 通信联调后移。默认 `PROBE_HARDWARE_VALIDATION=3`。Keil 打开 `project/MDK_V5/VibraNode.uvprojx`，Rebuild 后烧录 `project/MDK_V5/objects/VibraNode.hex`；不要烧录 tests/build 的仿真 AXF。

模式 3 独占采集、姿态、LED 和 RTT 输入，不运行协议应用。上电自动启动 ADXL 4000 SPS/±10 g、ICM 8000 SPS/±16 g/±500 dps；姿态支持 ICM 全部已配置 ODR，并固定重采样至 200 Hz。原始数据不应用本次校准，AGM 也不扣除外部校准。

## 首轮操作

1. 烧录后复位，连接 RTT channel 0。应看到 `M4-M8 single-board RTT` 和 `START ADXL=4000 ICM=8000 attitude_active=1`。正常采集中 LED 绿灯 1 Hz 双脉冲（100/50/100/750 ms）；不需要任何 USB 对端。
2. 静止平放至少 10 秒，保存完整日志。`samples/consumed` 持续增加，`spi/ovr/fmt/qdrop/gap` 应为零，`time_valid` 应收敛到 1；ICM 的 `tick_valid` 也应收敛（修复版用FIFO_COUNT读取观测，100 ms估计窗口，通常需至少约1秒；不要求水位IRQ持续增长）。`uncertain_batches` 是累计值，收敛后应停止增加，不要求归零。
3. `period_q16 / 65536` 为估计样本周期（µs），`65536000000 / period_q16` 为估计 SPS。与每秒样本增量比较；M3 参考约 ADXL 4054、ICM 8039 SPS，不能用名义速率强行判定丢样。时间模型仍为输出就绪时间，不代表两芯片同步或绝对误差已通过。
4. 默认档静止 3 秒后看 `ATT valid=1`、`in/out/processed` 增长、`attdrop/decode_drop=0`。`q30` 四元数各项除以 2^30，模长应接近 1。缓慢转动后应变化，停下应稳定；六轴 yaw 会漂移。
5. 输入 `x`，等待两路 `stop=1`。输入 `s` 启动、`r` 重启，重复 3 次；计数按会话复位，姿态重新收敛。`x` 是诊断中止，会丢弃硬件 FIFO 尾部，不能据此验收线缆 STOP 边界。
6. 输入 `2` 检查低速档，再 `3`、`4` 检查 ICM 16/32 kSPS；各档都应显示 `attitude_active=1`，`att processed` 持续增长且 `attdrop` 不持续增加。每次等待 10 秒，再 `1` 恢复默认。200 SPS 姿态仅适用于低于其 Nyquist 频率的运动，高频已经在传感器采样前折叠，不能由数字 FIR 消除。
7. 默认档静止运行至少 30 分钟，再记录性能、错误计数和栈。记录后可输入 `q` 暂停原始队列消费数秒，再 `q` 恢复；这是主动丢样注入，`qdrop/gap/segment` 增加属预期。按 `r` 开新会话重新观察正常条件。

## RTT 命令

| 命令 | 行为 |
|---|---|
| `h` | 帮助 |
| `p` | 立即报告状态及 RAM 中校准候选 |
| `s` / `r` | 等待两路异步停止后启动/重启 |
| `x` | 停止、取消正在采集的校准窗口；已完成候选保留 |
| `1` / `2` / `3` / `4` | 默认 / 250与200 SPS / ICM 16k / ICM 32k，自动重启 |
| `q` | 切换原始队列消费，取消进行中的校准 |
| `l` | 14 秒 LED 巡检：每态 2 秒，蓝常亮→蓝 2s 心跳(100/1900)→绿 1 Hz 双脉冲(100/50/100/750)→紫 5 Hz→红 5 Hz→红常亮→白闪 1 Hz(500/500)；结束恢复实际状态 |
| `c` / `n` | 开始 ADXL 六面流程 / 采集当前面 |
| `g` | ICM 静止陀螺零偏采集 |
| `w` | 两路均停止且存在完成候选时写 Flash；重复按不会重复写 |
| `v` | 两路停止时重新读 Flash，丢弃未保存候选 |

一次主循环最多读一个按键，RTT 非阻塞输出可能丢日志。按键前后留时间观察返回信息。灯语巡检是人工覆盖，14 秒内颜色不代表实际故障状态。

## 性能与栈

`PERF max_us acq/attitude/loop` 为从上电起观测到的最大单次轮询耗时，包含期间中断开销；loop 还包含日志/校准等操作。它不是百分比 CPU 利用率，也不是已证明的 WCET。保存 Flash 会拉高 loop 最大值，测量稳定采集时应先记录未保存前的值。

`stack_unused=N/2048`：C运行库完成后、main首次调用只填充当前MSP以下的未用栈，再执行板级初始化与应用；扫描到的最低覆盖边界用于估计高水位，包含执行过的板级初始化和中断，不包含之前的C运行库/SystemInit。N=0 或接近耗尽需停止验收并检查。非零不证明所有异常嵌套安全，未执行路径、未写入的栈预留区不会被完整反映。首版719c971的填充被C运行库清零，故其日志中的0/2048无效，不能据此断言溢出；须用修复版重新测量。M3 的性能数据不能直接代替带 AGM/校准的本轮结果。

## ADXL 六面校准与保存

1. `1` 恢复默认，等待两路开始连续采集。输入 `c`，按 **ADXL 芯片轴向**依次放置 +X、−X、+Y、−Y、+Z、−Z 朝上；不是未经核对的外壳坐标。
2. 每面摆放完成、静止后输入 `n`。采集约 1 秒的 4000 个连续 FIFO 样本；3 秒超时、格式/段/序号不连续、近满量程、运动或方向不正确均拒绝，可在同一面重新 `n`。
3. 默认质量门：每轴标准差 ≤0.02 g、目标面偏差和其余轴均值 ≤0.15 g；最后执行组件六面对称拟合及轴间比例差门。阈值为首轮验证设置，需根据真实静止噪声与摆放夹具验证，不代表标定精度认证。
4. 六面完成后 `CAL PASS in RAM`，`dirty=1`。`bias_ug` 单位 µg，`scale_ppm=1000000` 表示比例1。数学约定：`corrected_g = (raw_count / 52428.8 - bias_g) * scale`。
5. `x` 后等两路 stop=1，`w` 保存，看到 `SAVE PASS generation=N`。输入 `v` 或复位后 `p`，核对系数和 generation；复位会重新自动采集，但不会自动写 Flash。

本轮六面仅实现 ADXL 默认量程。ICM 加速度六面标定、跨量程适用性与精密坐标校正仍未完成。

## ICM 陀螺静止校准

恢复默认档并静止后输入 `g`。收集 8000 个连续 ICM 样本；陀螺每轴标准差 ≤1 dps、均值绝对值 ≤5 dps，辅助加速度每轴标准差 ≤0.02 g，均值重力模长在0.85～1.15 g之间。通过后仅替换候选陀螺字段，保留此前 ADXL 标定；`x`→两路 stop=1→`w` 保存。

反例测试：采集期间晃动探头，应拒绝，不改变已有候选。恒定小角速度可能通过静止门，因此仍要求操作者确保静止。温度仅存储该窗口均温，不实现温度补偿。运行中按 `w` 应明确拒绝。

## Flash 恢复

记录 v2 用存储代次判断新旧，`created_ms` 仅作本次启动时间；末两个2 KB扇区地址为 `0x0803F000` / `0x0803F800`，程序链接范围已排除这4 KB。v1 格式不会被当作v2读取，会回退默认，需要重新标定。下载器全片擦除仍可能清掉校准记录，应检查 Keil 下载擦除选项。

软件故障注入覆盖每个写入字前失败后的旧记录恢复。真实擦写/复位/写入中断电需实板单独验证：先保存一组并记录 generation，再完成不同候选，停止后 `w` 保存期间断电，重启核对读取到完整旧记录或完整新记录。切勿以软件测试声称实板断电保护已经验收。

## 回传材料

首轮请保留：启动到静止10秒的日志、转动与回稳、`x/s/r`、切档及恢复、LED观感、两种校准接受/拒绝与 `w/v/复位` 结果、长时运行末尾 PERF 和错误计数。先依据这些数据解决探头内部问题，再执行 [485验证](HARDWARE_CHECK_M4.md) 和 TAB5 开发。


## 首轮实板反馈后的重测重点

见 [2026-09-07实板反馈与修复](milestones/2026-09-07-rtt-board-feedback.md)。重新烧录当前模式3镜像并复位，默认档静止10秒，重点记录ICM `time_valid/tick_valid`、停止增加的`uncertain_batches`、非零`stack_unused`和PERF。随后每个2/3/4档至少运行10秒，再1返回默认。ICM水位中断不增长而样本持续增长是可出现的正常调度情况，不能用IRQ计数代替样本时钟。FIFO时间锚点含寄存器读取延迟与最多一周期样本相位不确定性，收敛只表示周期估计一致，绝对时刻精度仍待仪器验证。
