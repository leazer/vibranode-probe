# M3 双 FIFO 连续采集验证

烧录 `project/MDK_V5/objects/VibraNode.hex`。本次默认编译 M3；M2 快照入口保留，可将 `project/inc/probe_validation.h` 的 `PROBE_HARDWARE_VALIDATION` 改为 1 后重新编译使用。

## 当前固件做什么

上电自动以 ADXL 4000 SPS/±10 g、ICM 六轴 8000 SPS/±16 g/±500 dps 开始独立 FIFO 采集。配置回读、启动数据丢弃完成后，将原始 FIFO 批次交给有界队列。RTT 测试消费者计算滚动校验值并释放批次，每秒报告累计统计。

这不是全量数据上传：原始批次在固件内部消费后释放，没有保存整段记录，没有 RS485 正式协议或在线姿态。LED 保持熄灭，不能用来判断采集是否正常。

## 首轮操作

1. 烧录后记录上电起 10 秒 RTT 日志。两路应最终 `run=1 stop=0`，稳态相邻一秒日志的 `samples` 增量分别接近 4000 和 8000；首秒包含配置和稳定等待，不能据此判断速率。
2. 静置及翻转各记录几秒。`a`/`g` 是最近有效 FIFO 样本，不是旧快照寄存器。
3. 不操作时 `spi/ovr/fmt/qdrop` 应不增长，`seg` 应保持 1。传感器内部时钟与 MCU 不同，不能要求计数正好等于标称 ODR。
4. 输入 `x`，等待两路 `stop=1`；输入 `s`，重新开始且计数归零。
5. 输入 `2`，自动先停再切到 250/200 SPS；确认稳态样本增量。输入 `1` 返回默认速率。
6. 默认稳定后，再输入 `3` / `4` 单独验证 ICM 16/32 kSPS；这些是本地采集测试，不意味着链路已能持续全量上传。

如果出现 `fault=3`，请保留同一行的 `reg/expected/actual`，可定位配置回读失败。不要只发最后一行。

## RTT 单字符命令

| 命令 | 行为 |
|---|---|
| `s`、`r` | 请求停止后重新开始当前配置 |
| `x` | 诊断中止；丢弃硬件 FIFO 尾部，队列中已有有效批次仍可消费 |
| `1` | ADXL 4000 / ICM 8000 SPS，量程保留当前值 |
| `2` | ADXL 250 / ICM 200 SPS，量程保留当前值 |
| `3`、`4` | ICM 16000 / 32000 SPS，ADXL 与量程保留 |
| `a` | ADXL ODR 循环 250→500→1000→2000→4000 |
| `i` | ICM ODR 循环 200→500→1000→2000→4000→8000→16000→32000 |
| `d` | ADXL 量程循环 ±10/20/40 g |
| `e` | ICM 加速度量程循环 ±2/4/8/16 g |
| `g` | ICM 陀螺仪量程循环 ±250/500/1000/2000 dps |
| `q` | 暂停/恢复原始批次消费，用于主动制造队列满 |

每次改配置都经过停止再启动，不会在同一连续段内更换量程。`q` 暂停期间采集继续，四槽队列满后丢弃新批次并累加 `qdrop`，已有批次不会被覆盖。恢复消费后新数据使用新段号。最后可用 `r` 清零本次测试计数。

## 统计含义

- `samples`：已交付队列的有效样本总数；`consumed`：测试消费者已处理数量；不是 SPI 事务数。
- `batches`：有效批次数；`warmup`：启动阶段主动丢弃的样本数。
- `seg`：当前连续段；`gap`：未知长度缺口计数；已知数量的队列丢弃单独记 `qdrop`。
- `spi/ovr/fmt`：SPI 错误、FIFO 满/溢出、包格式或 ICM 时间间隔异常。发生后只重建出错传感器的采集段。
- `fifo_max_B`：查询到的 FIFO 字节高水位；`queue_max`：队列槽高水位，容量为 4。
- `irq`：ADXL DRDY / ICM FIFO INT1 的累计次数，二者含义不同，不能拿 ICM IRQ 次数当样本数。
- `poll_gap_max_us`：两次采集轮询间的最大时间；包含主循环其他工作的影响，需在实板观察。
- `tmst16`：最后一包 ICM 原始时间字段，会正常回绕。固件同时在当前连续段内扩展时间并检查相邻包间隔。
- `hash`：原始批次的滚动校验摘要，辅助确认消费者工作，不是通信 CRC 或无丢样证明。
- `fault` 保留最近一次原因直到重启本次采集：0 无、1 SPI、2 ID、3 配置、4 FIFO、5 格式/时间、6 队列、7 无数据。恢复后 `run=1` 但历史 fault 非零是允许的。

## 尚未验收的边界

所有批次设置 TIME_UNCERTAIN。ADXL 保留 DRDY 锚点，ICM 保留水位锚点及内部时间，但尚未拟合到统一 MCU 样本时间轴；不能用读取开始时间代表首样本时间。滤波预设是待实测候选，不保证通带幅值或跨传感器相位。

ADXL 芯片配置生成支持 HPF 0～6，但采集 API 当前明确拒绝 HPF 非零，待其较长稳定时间验证后开放。`x` 是诊断中止，不是设计中要求排空尾部的正式协议 STOP。
