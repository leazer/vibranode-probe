# 双 FIFO 采集实现计划

依据：已批准的探头设计第 3～6 节及组件分层整改。沿用当前独立固件分支。

- [x] 芯片层：有界配置表生成，检查 ODR/量程/HPF；ADXL FIFO 轴序/空标志检查；ICM 16 字节六轴包头/无效数据/时间检查。先写测试再实现。
- [x] 采集层：独立双设备状态、初始化回读、持续 FIFO DMA、每次有界读取、读后再查、错误与段边界、原始批次队列。
- [x] 验证入口：独立 M3 RTT 应用消费批次并报告计数/最近样本/队列高水位；保留 M2 编译选项，不把采集功能塞回 probe_validation。
- [x] 验证正常、短包、溢出、传输失败、队列满及停止/重启；Keil 全量编译后形成硬件验证说明及里程碑提交。

本阶段是采集链路验证固件，不声称具备正式协议、姿态或已校准时间映射。批次保留原始 FIFO 字节、读操作时间、IRQ 锚点、段号与序号；统一设置时间不确定标志，避免以 DMA 完成时间冒充样本时间。

ICM 配置采用字节计数、大端数据、16 字节包、时间戳绝对值 1 us、stop-on-full；读取分块不超过 512 字节并重新检查计数。ADXL 每次最多 32 组。两路都以周期兜底查询补充中断通知，不因丢失一次边沿停采。

状态所有权：各设备采集上下文持有配置序列、阶段、截止时间、错误/采样计数和队列；IRQ 邮箱仅持有计数与最后时间，主循环短临界区快照。芯片组件仍不接触平台。RTT 入口不执行 SPI 操作。
