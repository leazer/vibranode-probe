# M2：可烧录的板级诊断版本

日期：2026-09-07。开发分支 `codex/probe-foundation`，前一里程碑 `a68e14e`。

## 本次实现

- 双 SPI 独立 DMA 事务组件，各组件自有 TX/RX 缓冲，提交时复制临时 TX；调用方不能在传输中覆盖缓冲。
- RX 先使能，TX 后提供时钟。双方 DMA 完成并确认 SPI 不忙后释放 CS；超时/错误关闭传输并重置对应 SPI，不取消另一路。
- 默认硬件验证入口：自动读取 ADXL 三个身份字段与修订号、ICM WHO_AM_I，逐项写入及掩码回读配置，启动 4 kSPS/8 kSPS 模式。
- 每约 10 ms 读取一次数据寄存器快照，输出三轴/六轴原始计数；每秒汇总中断次数和最近间隔。不声称快照是连续采样流。
- RTT `r` 重试传感器，`l` 红绿蓝依次测试，`u` 5 Mbps 单次发送 64 字节 0x55，`v` 5 Mbps 限时接收校验同一模式。UART 测试完成/失败恢复 1 Mbps 接收。
- 新增状态分别集中在 SPI、传感器诊断和链路检查上下文；没有新增无组织的函数内静态状态。

## 软件验证结果

- Keil ARMCC 5.06 update 7 build 960，完整 Rebuild：0 Error(s), 0 Warning(s)。
- 固件大小：Code=15200、RO-data=1364、RW-data=16、ZI-data=5232 字节。
- SPI 模拟测试：非法提交、TX 拷贝、同路忙拒绝、双路独立、RX 单独完成、忙尾等待、DMA 错误、超时与重试通过。
- 诊断状态机模拟测试：身份检查、配置回读、三轴/六轴符号与偏移解码、单路错误不拖住另一路、人工重试、错误身份禁止继续配置通过。
- 原有时间戳回绕测试、RTT 集成测试和 4 组日志宏测试通过。
- 独立只读代码审查未发现阻止本轮诊断镜像上板的功能问题；按反馈修正 ICM INT_CONFIG1 注释，保持寄存器值 0x60。

模拟测试运行 ARMCC 编译后的实际组件代码，但替换硬件访问和时间源。它们不验证真实中断抢占、DMA 仲裁、SPI/UART 电气时序或传感器内部更新行为。
